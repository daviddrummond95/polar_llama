## Findings considered and rejected

Recorded so they are not re-audited next run:

- **Provider→string serialization "inconsistency"** (`inference_messages` uses
  `.as_str()` while other entry points use `str(provider)`): **not a bug.**
  `Provider.__str__` delegates to `as_str()` (`src/lib.rs:52-53`), so all entry
  points emit the same lowercase wire name. No plan.
- **Synchronous `inference` processes rows serially:** **by design, not a bug.**
  `docs/API_REFERENCE.md` explicitly documents it as sequential; `inference_async`
  is the parallel path. Worth a future deprecation note, not a correctness fix.
- **MCP Phase 2 (`agent_async` multi-turn ReAct loop):** **deliberately not
  planned.** `docs/design/MCP_TOOL_INTEGRATION.md` gates it behind adoption
  evidence (users chaining 3+ emit/execute rounds); building it on spec would
  contradict a settled decision doc.
- **"Custom providers" plugin system:** in tension with the deliberately closed
  `Provider` enum. The cheaper grounded path (OpenAI-compatible endpoints via
  `OPENAI_BASE_URL`) already works today; a plugin system is not recommended now.
